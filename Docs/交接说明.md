## 3. 常用命令与操作

**在 Unity 里**：菜单 `ZMZZ / 构建战斗原型场景` —— 用代码重建两个场景，并把入口界面设为第一个场景。

**命令行**（需要先关掉 Unity 编辑器，同一工程不能被两个实例打开）：

```
# 跑自动化测试
pwsh -NoProfile -ExecutionPolicy Bypass -File "E:\unity-codex\2D ZMZZ\Tools\run-unity.ps1" -Mode test

# 重新生成场景
pwsh -NoProfile -ExecutionPolicy Bypass -File "E:\unity-codex\2D ZMZZ\Tools\run-unity.ps1" -Mode method -ExecuteMethod "ZMZZ.EditorTools.PrototypeSceneBuilder.BuildFromBatch"
```

**不开 Unity 也能验证代码能不能编译**（编辑器开着时也能用）：

```
pwsh -NoProfile -ExecutionPolicy Bypass -File "E:\unity-codex\2D ZMZZ\Tools\compile-check.ps1"
```

## 5. 已经踩过的坑（别再踩）

1. **同一个工程不能同时被两个 Unity 实例打开**。命令行跑批处理前必须先关编辑器，否则批处理实例会直接崩（工程本身不受影响）。
2. **URP 2D 场景必须有全局光**（`Light2D` 设为 Global），否则 Sprite-Lit 材质全黑。场景生成器已经加了。
3. **中文 UI 需要带中文字体的字体**，`UITheme.DefaultFont` 会自动从系统字体里挑（微软雅黑等），新增文字别自己写 `GetBuiltinResource<Font>`。
4. **改时间流速只走 `Core/GamePause.cs`**。命中停顿系统也在改 `Time.timeScale`，两边直接改会互相顶掉（暂停失效）。
5. 写新界面用 `UIFactory`，中文说明见 `Docs/UI框架说明.md`。
