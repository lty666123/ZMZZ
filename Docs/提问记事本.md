## 2026-11-07

### 问题：为什么好友申请接口返回的是数组？

### 解释

`GET /friends/requests` 获取的是当前玩家收到的所有待处理申请。申请数量可能是 0 条、1 条或多条，因此服务器使用数组表示一组好友申请。服务器代码最后的 `.ToArray()` 会把筛选、排序后的结果转换成数组。

### 结论 / 做法

Unity 的 `JsonUtility` 不能直接解析顶层数组，所以把服务器返回的：

```json
[{"requestId":"..."}]
```

临时包装成：

```json
{"items":[{"requestId":"..."}]}
```

再用 `FriendRequestList` 的 `FriendRequest[] items` 解析，最后通过 `foreach` 逐条处理申请。
